System Overview

STRAIGHT v1.0 follows a hybrid deployment architecture. A remote GPU-enabled virtual machine is dedicated to executing OpenMMLab-based pose inference. The local client machine hosts both the web interface and the FastAPI-based API server, which orchestrates the workflow and communicates with the inference backend over SSH.

In our reference setup, the local client is a MacBook Air M2 (running the API server and frontend), and the remote inference server is an NVIDIA GeForce RTX 3060 GPU rented via Vast.ai. Other CUDA-compatible NVIDIA GPUs are supported with appropriate configuration changes.

1. Remote GPU VM Setup

All steps in this section are executed on the remote Linux VM to prepare the inference environment.

1.1 Miniconda Installation

Install Miniconda to manage Python environments:

wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh -b -p $HOME/miniconda3
source ~/miniconda3/etc/profile.d/conda.sh

Accept the Anaconda terms of service:

conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r

Create and activate a dedicated OpenMMLab environment:

conda create -n openmmlab python=3.8 -y
conda activate openmmlab

1.2 PyTorch and CUDA Installation

Install PyTorch with CUDA support. The CUDA version should match the GPU driver on the VM. The following command targets CUDA 12.1: 

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

1.3 OpenMMLab Stack Installation

Install the OpenMMLab core libraries required for detection and pose estimation:

pip install -U openmim
mim install mmengine
pip install "mmcv==2.1.0"
pip install "mmdet==3.2.0"
pip install "mmpose==1.3.2"

(Optional) Verify successful installation:

python -c "import torch; import mmcv, mmdet, mmpose; print(torch.__version__, mmcv.__version__, mmdet.__version__, mmpose.__version__)"

1.4 MMPose Repository and Weights

Clone the MMPose repository:

git clone https://github.com/open-mmlab/mmpose.git
cd mmpose

Download pretrained weights:

wget https://download.openmmlab.com/mmpose/v1/projects/rtmpose/rtmdet_m_8xb32-100e_coco-obj365-person-235e8209.pth

wget https://download.openmmlab.com/mmpose/v1/projects/rtmposev1/rtmpose-m_simcc-body7_pt-body7_420e-256x192-e48f03d0_20230504.pth

These models are used for robust single-person detection and full-body pose inference in unconstrained practice footage.

2. Secure Remote Access

To enable seamless interaction between the local client (API server) and the GPU VM, configure SSH key-based authentication.

Follow the Vast.ai SSH setup guide: Vast.ai SSH Setup

Ensure that the private key is available locally at:

~/.ssh/id_ed25519

Once configured, the API server can access the VM without repeated password prompts, enabling automated inference and data transfer.

3. STRAIGHT Application Setup

The following steps are performed on the local machine. The API server and frontend both run locally, while pose inference is offloaded to the remote GPU VM.

3.1 Repository Installation

Clone the STRAIGHT repository locally:

git clone https://github.com/straight-anon/STRAIGHT.git
cd STRAIGHT

3.2 API Key Configuration

Set the OpenAI API key environment variable locally:

export OPENAI_API_KEY="sk-..."

3.3 Backend API Server

Start the FastAPI backend locally:

uvicorn api_server:app --reload

This server orchestrates remote pose inference via SSH, computes metrics, and generates feedback.

3.4 Frontend Build and Deployment

Launch the interface locally:

cd web
npm run build
npm run dev

Versioning and Future Updates

STRAIGHT v1.0 currently relies on RTMPose within the OpenMMLab ecosystem for 2D pose estimation. We are actively transitioning to ViTPose-based pipelines to improve pose accuracy and temporal stability across frames. In parallel, we are optimizing end-to-end system latency and developing a real-time shot isolation algorithm that automatically segments individual shots from continuous practice footage. To further reduce computational cost, we are also fine-tuning a vision-language model for efficient and reliable release segmentation. Installation instructions will be updated accordingly in future releases.
